# Wisp brand

Aurora on ink: a single flowing swirl in a teal #2DE2C5 to violet #8B5CF6 gradient on ink #0B0D14, with a small teal comet dot. `logo.svg` is the app icon; `tray-mono*.svg` are black-only template images for the macOS menu bar, `tray-color*.svg` are the Windows tray glyphs, and the `-pending` variants add a bottom-right badge (violet with an ink ring in color, a cut-out solid dot in mono) so they are not confused with the comet. Open `preview.html` (served over http or file) to check every icon at 16 to 64 px on dark and light. Regenerate from `apps/wisp` with `npx tauri icon brand/logo.svg` and, for each tray SVG, `npx tauri icon brand/<name>.svg -o src-tauri/icons/<name> --png 32`, then delete `src-tauri/icons/android` and `src-tauri/icons/ios` (desktop only).
